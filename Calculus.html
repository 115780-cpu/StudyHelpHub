➕ Calculus

Calculus is the branch of mathematics that studies change and motion. It focuses on rates of change (differentiation) and the accumulation of quantities (integration). Calculus is widely used in physics, engineering, economics, computer science, medicine, and many other fields to solve real-world problems.

💡 Study Tip

Learn the basic differentiation and integration rules before tackling complex problems. Showing each step clearly will help you understand how each rule is applied and reduce calculation mistakes.

📝 Example Question 1

Question:

Find the derivative of:

f(x) = x²

Answer

Using the power rule:

f'(x) = 2x

📝 Example Question 2

Question:

Find the derivative of:

f(x) = 4x³

Answer

f'(x) = 12x²

📝 Example Question 3

Question:

Evaluate the integral:

∫ 2x dx

Answer

∫ 2x dx = x² + C

📝 Example Question 4

Question:

Find the derivative of:

f(x) = 5x⁴ − 2x

Answer

f'(x) = 20x³ − 2

📝 Example Question 5

Question:

Evaluate:

∫ 6 dx

Answer

∫ 6 dx = 6x + C
